# agent-render-cmd 实施计划

目标：建立独立 Rust 命令行 Markdown 渲染库，选择性移植 Glow/Glamour 的宽度策略、块级缩进与主题规则；流式调度自主实现。按行触发处理，按 Markdown 块保持语义，不把上游整套 Go 应用搬入项目。

## 首轮拆分步骤

- [x] 记录现有 release 基线，固定上游 commit，保存许可证与逐文件来源。
- [x] 新建 workspace crate 与接收 `Write`、显式配置和文本片段的接口。终端探测、环境变量和输入编辑保留在 agent-app。
- [x] 按上游来源建立 `upstream/glow`、`upstream/glamour` 私有模块。移植部分与自主实现的 Markdown 适配、流式调度、终端重绘分开。
- [x] 使用 pulldown-cmark 的块级事件和源范围维护未完成区域，支持嵌套列表、引用、跨行强调、表格与代码块；新片段到达即可预览。
- [x] 限制待解析文本与可重绘屏幕行数，明确超限、窗口缩放和纯文本模式的处理；保证正文不丢失，不能擦除已固定内容。
- [x] 接入 agent-app，删除旧的应用内 Markdown 实现；补充 README、来源说明及针对性测试。
- [x] 执行 fmt、Clippy、workspace/core 无默认 feature 测试、release 体积比较和伪终端流式交互验证。

## 模块归属

- `src/upstream/glow/`：Glow 宽度默认值和自动宽度上限策略的 Rust 移植。
- `src/upstream/glamour/`：Glamour 块栈、样式配置中实际采用部分的 Rust 移植。
- `src/markdown/`：自主实现的 pulldown-cmark 事件适配、块边界和表格布局。
- `src/stream/`：自主实现的增量缓存、提交/预览、重绘和降级。
- `src/ansi.rs`、`src/config.rs`：自主实现的文本样式/宽度处理及显式配置。

## 验收与边界

- 标题、嵌套列表、引用、跨行强调、代码围栏和表格可用；代码语法高亮不在首次拆分范围，后续接入见文末记录。
- 模型回复结束前即可看到文本；完整块不反复重绘。
- 分片边界、中文/组合字符、满行、表格列对齐、超限、缩放、输出错误有针对性测试。
- 不依赖 Go 工具链、Glow 外部进程、异步运行时或新的 UI 框架。
- README 区分直接依赖、实际移植、设计参考与自主实现，注明不保证已提交块的后置引用链接重排。

- 另一处修复：代码块中的空行也绘制当前前缀，保留连续竖线和闭合边框。
- 回归：加强原先仅检查“曾输出表头”的流式测试；增加部分数据行、所有 UTF-8 两段切分、代码空行测试。新渲染库共 22 项测试通过。

## 持久状态栈重构计划

将整个生产渲染入口改为状态栈驱动，不再把所有类型都交给不断增长的未完成 Markdown 字符串重解析。栈记录列表/列表项、引用等容器，以及段落、标题、代码、表格、HTML 等叶子状态；完整行触发状态转移，片段只更新当前可编辑行/局部候选区。

- [x] 统一进入/退出和容器上下文；各类型按栈顶分发。
- [x] 段落/标题使用局部行内解析与有限前瞻，列表/引用保留缩进和编号。
- [x] 围栏和缩进代码逐行提交，保持高亮状态；长度和窗口变化不再丢失块类型。
- [x] 表格单独保留受限候选行，列宽确定后逐行输出；HTML 独立流式状态。
- [x] 删除原全块重绘/原文回退入口，覆盖长代码、长列表、跨片段、跨容器、缩放与样式恢复。
- [x] 验证现有样例、feature 矩阵、格式/Clippy/workspace/core 检查和 release 体积。


### 持久状态栈重构结果

- 生产入口现为 `stream/state`：实际栈帧包含列表、列表项、引用及叶子状态。栈顶覆盖段落、标题、分隔线、围栏/缩进代码、表格与 HTML；各类型有独立的推进和退出规则。
- 删除旧 `stream/fallback.rs`、全局 `pending` 和 `stable_prefix` 提交逻辑。布局用的 Glamour 块栈与本项目的持久语法栈分开，未改动上游移植归属。
- 代码仅保留语言、围栏/缩进信息、Syntect 检查点与当前输入行。测试验证 2,000 行 Rust 代码跨滚屏后仍保持面板，代码正文的 1,000 行不会再次调用 Markdown 解析器。

- 当前输入行、段落内联候选和表格候选仍有明确上限。超长单行可额外折行或使用普通代码样式，过长未闭合行内语法可按字面内容固定，但不会切换成整个文档的原文回退模式。
- 加入仅测试使用的 vt100；测试真正消费 ANSI 输出，检查滚屏、颜色、缩放、内容完整性和不同分片方式的等价性。

## 行内 sub / sup 补全（2026-09-09）

- 上轮 HTML 内联样式仍未包含上下标。本轮先以正文与表格的逐字符输入复现 `<sub>` / `<sup>` 原样显示，再加入回归用例修正。

### LaTeX 接入结果

- `agent-render-cmd` 新增可选 `math` feature；`agent-app` 默认启用 `math` 和 `syntax-highlighting`。没有 Node/Go 运行时、Python 绑定或新增终端 UI 框架；SQLite 与原发布配置保留。

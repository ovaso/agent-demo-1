## 归类与维护约定

- 通用开发原则与机制归入 `common`；文档包含项目实例时，明确其适用范围，不将项目变量、默认值或限制视为通用标准。
- Agent 特有的上下文、执行流程、预算和工具协议继续放在对应领域目录；其他领域文档通过链接引用通用机制。
- 当前规则与历史记录明确区分。规则变化时更新当前说明；重要决策和历史验证标明适用版本或阶段。
